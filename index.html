Persona is a local-first personal workspace — notes, tasks, and an AI chat that answers from your own files.

No accounts · No cloud · No database · MIT licensed
★ Star on GitHub Get started

One command and you're in

$ persona   # starts local server, opens your browser

📄 Plain Markdown forever

If Persona disappeared tomorrow, your data is still a folder of .md files any editor can open. Zero lock-in.

🧠 AI that knows your files

Chat is grounded in your actual notes and tasks — answers cite the files they came from instead of guessing.

✅ Tasks with context

A personal task list with project tags that the AI can see, so "what should I do next?" actually works.

🔒 Fully local option

Point it at Ollama or any OpenAI-compatible endpoint and nothing ever leaves your machine.

Ask your workspace anything

You: what did I write about the apartment hunt last week?

Persona: From notes/apartment.md: you narrowed it to two places near Campus Ave and wanted to decide by Sept 1. Your task list has "tour Falcon Towers" scheduled for Friday…

Built for macOS · Apple Silicon first

Node.js ≥ 20 · clone, install, run. Voice input runs on Metal.
