# Contributing to Persona

Thanks for your interest in improving Persona!

## Getting started

```sh
git clone https://github.com/jayamitkatariya/personacli.git
cd personacli
npm install --allow-scripts=persona
npm run build
npm run dev   # start the local server in watch mode
```

## Ground rules

- Everything stays plain Markdown on disk — never introduce hidden state, cloud calls, or accounts.
- macOS-first, Apple Silicon friendly. Windows/Linux compatibility ideas welcome as issues first.
- Keep dependencies lean. Ask before adding anything heavy.

## Submitting changes

1. Open an issue for anything non-trivial so we can align before you code.
2. Create a feature branch, keep commits focused.
3. Make sure `npm run build` passes and describe what you changed and why.

Bug reports and feature ideas: use the issue templates. Thanks for helping!
